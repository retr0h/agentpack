# Threat Model

Analyze the project architecture and generate a STRIDE-based threat model.

## Output format

For each threat:
1. **Category** (Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation)
2. **Description** of the threat
3. **Affected component**
4. **Mitigation** recommendation
